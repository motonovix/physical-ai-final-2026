# Physical AI講座 2026 最終課題

東京大学 松尾・岩澤研究室 **「Physical AI講座 2026 基礎編」** の最終課題に取り組むためのリポジトリです。

## 講座について

- 主催: 東京大学 松尾・岩澤研究室
- 期間: 2026年6月25日〜8月6日（全7回・オンライン）
- 講座ページ: https://weblab.t.u-tokyo.ac.jp/lecture/course-list/physical-ai/

[LeRobot](https://github.com/huggingface/lerobot) をシミュレータ上で動かしながら、データ収集・学習・評価の一連の流れを学ぶ実践型の講座です。講義終了後に、約1ヶ月の最終課題があります。

| 回 | テーマ |
|---|---|
| 第1回 | Physical AIの概要 |
| 第2回 | Physical AIの活用 |
| 第3回 | Physical AIの学習（模倣学習） |
| 第4回 | Physical AIの学習（強化学習） |
| 第5回 | スケーリングとアーキテクチャ |
| 第6回 | 実世界データの収集 |
| 第7回 | Physical AIの実運用 |
